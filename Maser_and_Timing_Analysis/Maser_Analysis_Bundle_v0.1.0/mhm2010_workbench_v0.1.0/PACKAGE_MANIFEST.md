# MHM2010 Delivery Manifest

Application 0.1.0; writer 0.0.22; documentation 0.1.0. Build date: 2026-11-03.

- Runnable Python source, runtime requirements, pinned tested runtime versions and Windows launcher.
- GPL license and revision history, retaining the supplied writer's attribution.
- A 15-page bookmarked operator/scientific PDF and editable LuaLaTeX source.
- A historical 30-day FITS/HMD analysis with source hashes, CSV/JSON, native Veusz HDF5 and Stable32 PHD/FRD.
- A 29-page bookmarked Veusz rendering, per-page previews and GUI captures.
- Thirty-six passing regression tests and an environment-version record.
- SHA256 checksums for the packaged files.

The original user uploads are not duplicated wholesale: the example includes derived timing tables, all raw channel-pair datasets in HDF5 and overlapping HMD rows. Use the original input files with the batch script to reproduce the full import audit. The original FITS archive, original full HMD, and large Franks reference document remain separate user-provided inputs.

All implementation and verification occurred in the cloud workspace. No remote Git push or instrument write was performed. Bracca was not available as a connected device, so no local staging is claimed.

T4 planning is intentionally absent from this initial delivery. It begins only after this MHM2010 package is posted for download.
