#        (Linux x86-64, glibc >= 2.28: RHEL 8/9) and the monitor, exporter and
#        dashboard test suites pass. FIRST upgrade pip: the pip bundled with
#        Python 3.7 (20.1) cannot read the manylinux_2_28 tags of PySide6 6.5.3:
#            python -m pip install --upgrade "pip<24.1"      (24.0 = last for 3.7)
#            python -m pip install --only-binary=:all: -r requirements-py37.txt
#        RHEL 9 has no Python 3.7 package: create the interpreter with mamba
#        (install.sh --mamba --py37, or environment-py37.yml).
# 1.6.0: + h5py==3.8.0 and qtpy==2.4.3 (last cp37 / 3.7-capable releases,
#        resolved with pip download --python-version 3.7 --only-binary=:all:);
